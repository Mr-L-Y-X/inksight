## 固件配网页（captive portal）滚动 + 备用 WiFi 体验修复

文件：`firmware/data/portal_html.h`（唯一改动文件，纯 raw string 内的 HTML/CSS/JS）

### 1. 配网页无法滚动（用户报障）
- Chromium/WebKit 仿真下原页面其实能滚（scrollY 到 236/230）。真凶是 `body{display:flex;align-items:center;justify-content:center;min-height:100vh}`
  这写在部分手机内置 WebView / 配网弹窗里会导致上下裁切且滚不到顶部。
- 改为 `flex-direction:column; justify-content:flex-start` + `.card{margin:auto 0}` + `min-height:100dvh` 兜底。
- 顺带修：`html{overflow-y:scroll}` 去掉、加 `-webkit-overflow-scrolling:touch`、
  `.card` 加 `position:relative`（原来语言按钮 absolute 相对初始包含块，桌面上飞到窗口最右）、
  `.wn` 加 `min-width:0;overflow-wrap:anywhere`（长 SSID 撑破卡片）。
- 删掉页面加载时的 `ssidIn.focus()`（移动端会顶键盘挤视口），改为点「手动输入」tab 才 focus。

### 2. 配网页会把自定义后台地址覆盖成官方地址（真实 BUG，已实测复现并修复）
- 原因：初始化时 `/scan` 先发。ESP32 WebServer 单线程，`WiFi.scanNetworks()` 阻塞 1–4 秒，
  `/info` 排在后面；这期间 `infoReady=false`、模式停在默认 official，用户点「连接」或「连接并保存」
  就把 `https://web.inksight.site` POST 给 `/connect_saved`、`/save_wifi`，设备端 `saveServerUrl()` 直接写 NVS。
- 修法：把 `/scan` 抽成 `scanNetworks()`，初始化改为 `loadDeviceInfo().then(scanNetworks)`；
  另加 `infoReady` 守卫，未就绪时 `setServerForConnect()` 返回 false 并提示 msgLoading。
- 实测：info 未返回时点两个按钮都 0 次提交；返回后提交值 = 已保存的自定义地址。

### 3. 加完备用 WiFi 无法退出配网
- s1 原本没有任何重启/退出入口，只能等 `PORTAL_MANUAL_TIMEOUT_MS`（10 分钟）超时进 deep sleep。
- 新增「完成，重启设备」按钮（`#doneWrap`，仅在「仅保存到列表」成功后出现）→ `doDone()` → POST `/restart`，
  不跳 localhost（此时手机连着热点，跳过去没服务）。

### 4. 其他修复
- `cancelCountdown()` 原来 `document.querySelector('.cd').textContent=...` 会删掉倒计时 span，
  之后 `resetP()/showSuccess()` 里 `getElementById('cdN')` 变 null 抛错。改为只改 `#cdSuffix`。
- `resetP()` 补上恢复 suffix 文案、重新启用取消按钮、隐藏 doneWrap。

### 待确认（未做）
- **前端端口未持久化**：`storage.h` 只有 `cfgServer`，没存 frontendPort，重新配网永远回到 3000。
  自建后端且非 3000 端口的用户会跳错地址。修法需：storage 新增 `cfgFrontendPort`（NVS 键如 `front_port`）
  + `/info` 返回 + `/save_wifi` `/connect_saved` 接收 port 字段 + 页面回填。

### 知识点（本项目的多 WiFi 机制）
- `MAX_WIFI_NETWORKS=5`，NVS 存 SSID/pass 数组；`addWiFiConfig()` 追加到末尾，已存在则更新并提到 slot 0。
- 开机 `connectWiFi()` 按顺序逐个试，第一个成功即停，并把该网络提升为主网络（写回 cfgSSID/cfgPass）。
- 长按 `PIN_CFG_BTN` 进配网；进配网不清 NVS，所以「已保存网络」列表还在。
- 配网入口只在固件 captive portal 里，webapp/backend 没有 WiFi 远程管理接口。

## 配网页配置页跳转改为「用填写的服务器地址推 /config」

文件：`firmware/data/portal_html.h`（仍为唯一改动文件）

- `getConfigUrl()` 原来自定义模式写死 `http://localhost:前端端口/config`，公网部署时 localhost 指手机自己，跳不过去。
  改为用 `srvUrl` 解析出 origin：域名走 80/443 反代 → `https://域名/config`；IP（局域网后端 :8080 + 前端 :3000 同机）→ 端口换成「前端端口」。
  带 path 的地址（如 `https://x.com/ink`）保留 path → `/ink/config`。
- `LOCAL_DEFAULT_SERVER` 从 `'http://本地服务IP:8080'` 改为 `''`：以前点「自定义服务」输入框里会预填这条假地址，
  用户直接点「连接」会把假地址存进 NVS。现在留空 + placeholder，空值时前端不发 server 字段，设备保持原值。
- 同步改了 `srvCusTip1/srvCusTip2`（中英）与静态 HTML 兜底文案，说明「公网域名忽略前端端口」。
- 验证：`C:/Users/lyx/AppData/Local/Temp/portal_test/probe_cfgurl.js`（8 组输入）+ `probe_e2e.js`（官方服务页提交 → 跳转 URL 带 prefer_mac+code）。

## 宝塔部署关键点（用户域名 inksight.lanyx.online）
- 两道 Host 白名单都要配：webapp `proxy.ts` 读 `INKSIGHT_ALLOWED_WEB_HOSTS`（不配全站 404，build 前写进 .env.production）；
  backend `LanTrustedHostMiddleware` 读 `INKSIGHT_ALLOWED_HOSTS`（不配 /api 返回 400 Invalid host header）。
- 固件只内置 ISRG Root X1，必须 Let's Encrypt + fullchain + RSA（ECC 不一定支持），Nginx 443 反代到 Next 3000，Next rewrite 转 127.0.0.1:8080。
- 前端走同源 rewrite，浏览器不直连后端，CORS 不用配。
